# Raksha Shetty — Personal Portfolio & Creative Architecture

A high-performance personal portfolio featuring editorial typography, WebGL 3D graphics, fluid 60fps micro-animations, and an interactive CLI terminal simulator.

---

## ✨ Features

- **Editorial Typography & Choreography**: Custom scroll-driven entrance inspired by contemporary high-fashion editorial layouts.
- **Royal Maroon Aesthetic & Atmosphere Modes**:
  - 🍷 **Royal Maroon & Alabaster** (`#800000` signature luxury palette)
  - 🌙 **Velvet Obsidian & Deep Maroon** (Dark mode with glowing crimson accents)
  - 🍇 **Imperial Wine & Garnet Glow** (Rich wine-toned editorial variant)
- **High-Definition Executive Imagery**: Studio portraiture and transparent cutout integration with ambient radial backlighting.
- **Three.js WebGL & 2D Mist Shaders**: Real-time reactive geometric canvas and ambient particle mesh.
- **Interactive In-Browser CLI**: Functional command line terminal simulating bash commands (`help`, `skills`, `matrix`, `hire`, `clear`).
- **Telemetry & Architecture Modals**: Deep dives into distributed systems, tech stacks, and live simulated telemetry.
- **Command Palette (`⌘K`)**: Quick navigation, theme cycling, and audio toggling HUD.
- **Web Audio Synthesizer**: Subtle harmonic sine feedback on interactions.

---

## 🛠️ Tech Stack

- **Core**: Vanilla HTML5, CSS3, JavaScript (ES6+)
- **Graphics & Animation**: Three.js, GSAP 3, ScrollTrigger
- **Typography**: Outfit, Plus Jakarta Sans, Fira Code
- **Architecture**: Zero external runtime framework overhead, 100% responsive

---

## 🚀 Getting Started

Clone the repository and launch a local web server:

```bash
git clone https://github.com/rakshashetty01/Porfolio.git
cd Porfolio
python3 -m http.server 3000
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
